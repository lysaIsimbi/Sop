# Weekly Progress Reports

One report per week, sent by email every Friday by 11:59 PM CAT. This folder keeps a copy of each report as sent, so the archive here matches the email archive.

## How to send

- To: primary supervisor or team lead.
- CC: all team members and Emile.
- Plain text in the email body. No attachments.
- Subject line, exactly: `YYYY-MM-DD Progress Report Firstname Lastname`
  Example: `2026-09-14 Progress Report Birhanu Shimelis`
  The date is the Friday you submit.

The reports go into an automated archiving system. Do not change the subject format, the heading order, or the heading text. Keep every heading even when it is empty; write "None this week." under it.

## Workflow

1. Copy `TEMPLATE.md` to `YYYY-MM-DD_Progress_Report_Firstname_Lastname.md` (Friday's date).
2. Fill in every heading. One to three bullets per heading is usually right.
3. Paste the body into the email as plain text, set the subject line, send.
4. Keep the file here as the sent copy. Do not edit it after sending.

## Writing rules

- Brevity is fine. A weekly report is not a chapter.
- Be honest about what did not get done. "Planned tasks not completed" is where the plan and reality diverged; that is more useful than a clean sheet.
- Use "Comments and observations" for real blockers and asks. A week-long silent block is worse than asking.
- Material read and documents written must be hyperlinked (paste the full URL in plain text).
- Questions about the format go to Emile or the team lead.

## Body format

```
Hello <supervisor or team lead name>

Please find below the progress report of the past week.

1. Overview of last week's work:
   - Overview of items done

2. Planned tasks completed:
   - Tasks
   - None this week. (if there is no task completed)

3. Planned tasks not completed:
   - Tasks
   - None this week. (if there is no task completed)

4. Unplanned tasks completed:
   - Tasks
   - None this week. (if there is no task completed)

5. Tasks planned for the coming week:
   - Tasks

6. Material read and summarised:
   - Full reference of the material (hyperlinked)
   - Any blog or resource (hyperlinked)

7. Documents written or updated:
   - Link to a project or issue on Linear
   - None this week. (if there is no task completed)

8. Comments and observations:
   - Comments or any blocker
```
