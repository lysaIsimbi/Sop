# In-Situ SOP Materials Inventory

This inventory covers 41 of the 44 SOPs currently listed in `In_Situ_SOPs/README.md`. Load and Run the Oven Tray, Check Out Tools from the Crib, and Return Tools to the Shadow Board are listed in that README but are not yet itemised here. Quantities are per episode unless noted otherwise. Fixed installations are separated from movable tools and consumable or input materials so the list can be used for procurement and station setup.
